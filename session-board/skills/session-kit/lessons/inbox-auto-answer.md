Every time a task finishes, open the session board's "Inbox (your asks, captured)" section and start answering or handling its items right away, removing each one once handled.

**Why:** asks typed while a turn runs are captured to the Inbox, and without this rule they pile up unanswered.

**How to apply:** at the end of each task, before reporting idle, read the Inbox in the board file (`/board path` shows where it is); act on each item or answer it in chat, then remove it. Production writes, pushes and merges still need the person's word. Related: [[session-board-source-of-truth]].
